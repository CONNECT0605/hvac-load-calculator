  単位すきま(風量): 0回

## 6. 施工・運用上の注意(§19の観点)

- 本COREは **SI単位(kW・m²・m³/h・℃・%)** で計算します。SF・BTU/hr・tonnage は使用していません。
- 係数が出典付きでない項目(§1のFAIL)は計算に寄与させず、`notVerified` に列挙します。
  **数値を創作して帳票に載せることはしません。**
- `uValue` を直接入力した場合はその値を優先し、材料構成(厚さ・熱伝導率)を入力した場合のみ
  `U=1/(Ri+Σt/λ+Ro)` で算定します。
